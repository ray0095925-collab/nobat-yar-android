# نوبت‌یار رانندگان عباسپور

اپ اندرویدی سبک برای دسترسی به سامانهٔ نوبت رانندگان انبار. این نسخه، رابط وب مستقل نصب‌شده روی `raymand.site/nobat-ranandegan/` را در یک پوستهٔ اندرویدی باز می‌کند؛ ورود رانندگان با کد ملی‌پیامک و مدیریت مأموریت‌ها از همان سرور انجام می‌شود.

## ساخت APK

با هر push روی شاخهٔ `main` یا اجرای دستی workflow به نام **Build Android APK** در GitHub Actions، فایل نصب‌پذیر `app-debug.apk` ساخته و به‌صورت artifact برای ۳۰ روز نگهداری می‌شود.

## نکات

- دکمهٔ «ورود مدیر» صفحهٔ ورود WordPress را در همان WebView باز می‌کند و پس از ورود مدیر به پنل مأموریت‌ها برمی‌گردد.
- مقصد، تاریخ و فاکتور را مدیر تعیین می‌کند. راننده فقط درخواست تغییر زمان می‌فرستد.
- لوگو و فونت‌های همراه برنامه از فایل‌های ارائه‌شده توسط کاربر هستند.
- برای ارسال OTP، تنظیمات ملی‌پیامک باید در پنل WordPress افزونهٔ نوبت‌یار ذخیره شود.
